# Peak 11 · 健体冲刺

11天（2026-11-12 → 11-22）备赛冲刺日志 PWA：饮食记录、体重与身体状态、训练打卡、日报长图/Markdown 导出。纯静态、无服务器、数据全部保存在本机（IndexedDB），支持离线使用。

**线上地址：https://fujiimoku.github.io/peak11/**

## 添加到 iPhone 主屏幕

1. 用 Safari 打开上面的链接。
2. 点底部「分享」按钮（方框带箭头）。
3. 选「添加到主屏幕」→ 确认。
4. 从主屏幕图标打开，即可全屏、离线使用。

## 每天使用流程

- 早上：记录页输入晨重。
- 吃饭：按计划吃 → 餐卡上点「已吃(按计划)」；量不同 → 点已吃条目改重量；称了前后重量 → 用称重差值计算器；食堂菜 → 自定义食物（油量按 0–15g 自己估）。
- 训练：勾选动作、点「记录」填实际重量×次数，记录页填实际时长。
- 晚上：选最多4张当天照片 → 「生成日报长图PNG」→ 分享/长按保存发到 ChatGPT 对话；或「复制日报文字」发 Markdown 版。

报告只包含实际已记录的数据，计划未吃不计入；未填写显示「未记录」。

## 备份

「日报·设置」页 → 导出 JSON 备份（含照片），保存到「文件」App 或发给自己；换设备/清缓存后用「导入 JSON 恢复」。

## 本地运行

任何静态服务器即可，例如：

```
python3 -m http.server 8000
# 打开 http://localhost:8000
```

无构建步骤、无依赖。文件说明：`data.js` 预设食物库/菜单/训练计划，`db.js` IndexedDB 存储与备份，`app.js` 页面与交互，`report.js` 日报 PNG/Markdown 生成，`sw.js` 离线缓存。
